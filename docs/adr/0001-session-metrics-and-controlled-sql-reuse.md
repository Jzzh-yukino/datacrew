# 会话口径与受控 SQL 复用边界

DataCrew 将通过 Agent 主动检索口径、表关系和字段取值，形成带证据的查询计划；支持的结构走受控 SQL 编译，复杂结构保留自由 SQL 生成分支。新增业务计算定义须由用户确认，确认后的定义只在同一 `session_id` 内复用，不自动写入共享口径注册表。

自动复用缓存只接收受控编译路径的 SQL，每次命中仍重新检查执行条件并查询数据库。自由 SQL 即使执行成功，也不获得自动缓存资格，以减少尚未充分约束的语义错误被重复使用；代价是复杂重复问题仍需生成与校验。

这些是已确认的设计决策，功能尚未实现。具体流程、建议初值与验收要求见[架构设计稿](../design/sql-accuracy-and-reuse.md)。
